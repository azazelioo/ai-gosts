# ESPD

Находит четыре заголовка руководства оператора по п. 1.2 ГОСТ 19.505-79 (изменение 1) в текстовом слое PDF. Учитываются регистр, пробелы и цифровая нумерация. Страницы с заголовком оглавления пропускаются. При скане, объединённом разделе или другом названии результат review требует просмотра. Стандарт допускает объединение разделов. Содержание разделов и тип документа оцениваются отдельно.

Установка из корня ветки командой `python -m pip install ./espd`. Запуск целого документа — `python -m espd document.pdf --output reports`. Для выбора физических страниц добавьте `--pages 1 3`.

Из Python доступны `from espd import analyze_pdf, capabilities` и `analyze_pdf(path, output_dir=directory)`. В результате доступны `.report` и `.directory`. JSON версии 1 содержит SHA-256 исходника, результаты по физическим страницам и основание проверки. Обработка локальная, на правилах.

Версия 0.2 читает текстовый слой через MuPDF. Для страниц с небольшим количеством текста и крупным изображением используется локальный русский OCR. Укажите --tessdata или TESSDATA_PREFIX с каталогом rus.traineddata. В headings сохраняются короткие фрагменты текста после заголовка. Поддерживаются переносы и некоторые явно объединённые названия разделов. message_review_pages указывает найденные в тексте упоминания сообщений для проверки оператором. Это основания для просмотра, автоматическая оценка достаточности содержания пока не выполняется.

Поле toc_checks сопоставляет напечатанный в оглавлении номер со страницей заголовка. matching_pages содержит физические страницы PDF. selection_scope показывает, весь ли документ был доступен модулю.
