# ESKD

Сопоставляет размеры MediaBox с форматами А0–А5 и производными форматами таблицы 2 ГОСТ 2.301-68 в обеих ориентациях. Допуски сторон взяты из таблицы 3. Масштаб PDF UserUnit и поворот страницы учитываются. Принадлежность документа к ЕСКД требует отдельной проверки. При несовпадении размеров результат получает статус review.

Установка из корня ветки командой `python -m pip install ./eskd`. Запуск целого документа — `python -m eskd document.pdf --output reports`. Для выбора физических страниц добавьте `--pages 1 3`.

Из Python доступны `from eskd import analyze_pdf, capabilities` и `analyze_pdf(path, output_dir=directory)`. В результате доступны `.report` и `.directory`. JSON версии 1 содержит SHA-256 исходника, результаты по физическим страницам и основание проверки. Обработка локальная, на правилах.

Версия 0.2 по умолчанию ищет четыре непрерывные линии рамки и проверяет подписи граф в правом нижнем углу. В layout возвращаются рамка, контекстная вырезка штампа, текст и масштаб при однозначном чтении из текстового слоя. Для растровых листов применяется локальный OCR выбранного фрагмента после удаления длинных линий. Параметр --tessdata указывает каталог rus.traineddata. Рукописные записи, вложенные рамки, повёрнутые внутри листа штампы и полнота нормативного заполнения требуют просмотра. Режим --formats-only (в Python layout=False) пропускает визуальный анализ.

## Размерные надписи чертежа

В версии 0.3 команда `python -m eskd drawing.pdf --pages 89 --output reports` читает размерные надписи на выбранном листе. При обработке целого PDF режим auto выбирает страницы с распознанным штампом. Для рисунков без штампа укажите физические страницы или используйте --dimensions on. Режим --dimensions off отключает чтение надписей.

Поле dimensions.items хранит исходный текст, разобранную надпись, метод чтения и рамку в точках отображаемой страницы. Поддержаны диаметры, радиусы, углы, фаски, симметричные и некоторые односторонние отклонения, поля допусков и размеры в скобках. Отдельно напечатанное отклонение присоединяется при совпадении направления текста и близости рамок. preview указывает на исходную страницу с разметкой. Синие рамки обозначают разобранную нотацию, оранжевые требуют просмотра.

Крупные растровые вставки проверяются локальным OCR в двух ориентациях с --tessdata. Одиночные числа могут быть табличными значениями или номерами позиций. Для них и для OCR всегда выставляется review. Автоматическая связь с ребром, единицы по умолчанию, полнота извлечения и соответствие размера нормам требуют отдельной проверки.

На векторных чертежах dimension_line содержит координаты линии с двумя стрелками. Она показана зелёным цветом. Геометрическая связь с поверхностью детали требует отдельной проверки.
